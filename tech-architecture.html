§1 — System overview

The Office is an isometric live floor view of an agent org: a stdlib-only Python server collects truth about real agent seats (folders, git, tmux, PRs) and projects it to a zero-dependency canvas client. Standing doctrine: the office invents nothing · one STATUS parser (floor never diverges from sweep) · stdlib only, no CDN, no build step · a finished seat outranks a live one · all writes through one spine (W0) · anything that cannot survive the bake is not done.

§2 — Server architecture

2.1 Entry: serve.py (263 lines — CLI, wiring, nothing else)

Post SM7/SM8 the monolith is gone. serve.py parses flags, resolves roots, builds the Building, starts ThreadingHTTPServer with http.Handler. Flags at #276: --port --host --demo --poll --once --json --check --allow-actions --org --floor --floors --office-state. Env: $OFFICE_ALLREPOS (root rung 1), $OFFICE_FLOORS, OFFICE_ROSTER_ONLY=1 (process-wide; a floor with no manifest renders empty). --floors N requires --demo.

§3 — Client architecture

3.1 The OFFICE module registry (office.boot.js)

Zero-framework module system: OFFICE.module(name, deps, factory) registers into OFFICE._reg; need(path, by) throws by name on unresolved deps (the structural answer to "a missing identifier kills the whole floor"); seal() closes registration after the manifest-count check. Load order = script-tag order in static/index.html; office.main.js owns the requestAnimationFrame(frame) loop.

§4 — Data contracts & pipelines

4.1 /api/state

Handler → Building.resolve(floor) → World.state() → JSON. Byte-identity doctrine: client PRs must not change the payload; legacy single-floor emits no building key (pin proven 0-diff). Feed events are produced server-side by _diff() — the client renders, never invents. Known invariant break (SOL-013, open): the #267 write-mode toggle surfaces capability state via /api/state; the fix rides with the W0 spine work.

4.2 Office-state + choreo

officestate.py is the sole writer (atomic, strictly validated). The choreo engine runs truth-first: deterministic scheduling of validated fiction bits; any truth delta (suppression flag, real ask, state change) sets truth_suppressed and fiction yields. Nothing fictional goes live without per-type founder rulings + adversarial re-verification. The flagship first case is SMOKE-1 (stale seat walks to the smoking apron — worked example of record in CHOREO.md §3.3b; end-to-end sequence in §7): truth-triggered, tame, cast 1, full suppression invariant.

4.3 W0 write spine — specified vs at-tip

Specified (CONTRACTS §4, frozen): four conjunctive gates on every write — Host (loopback+allowlist) ∧ Origin (exact+header) ∧ Token (per-run X-Office-Token, constant-time) ∧ Capability (per-verb) — plus preview/commit bound by preview_hash, idempotent effects, ledger attribution before effect visibility.

At #276 (SOL-013 route probes): the four W0 routes (/api/action/preview, /api/action/commit, /api/capabilities, /api/ledger) return 404 — fail-closed. actions.py/ledger.py are sound as modules; cockpit-message is registered but unreachable over HTTP. Gaps before any W0 route ships: no token mechanism in the tree; --host accepted without loopback refusal; runtime re-arm via same-origin + static header alone; direct dispatch() skips the capability check. SOL-076 and COC-2 stay blocked on exactly this list; SOL-012 adds the stored attribute-XSS class + missing CSP as a HARD BLOCK.

4.4 Bake pipeline (build_standalone.py)

build(): live snapshot minus VOLATILE keys → script_manifest() inlines every manifest script (the same manifest §3.1 seals against) → inline_plate_assets (data-URIs) → one offline HTML artifact (1.76 MB at #276, pins green). The bake carries the client, snapshot, assets, theme. It does not carry polling, actions, attach, or cockpit — a baked floor is read-only by construction. This page obeys the same rule so the bake can carry the architecture doc itself.

4.5 Asset pipeline

static/assets/ + MANIFEST with provenance classes (#211 scaffold, #251 Manhattan provenance + regenerated CREDITS #224; PNG intake #210 rejects non-PNG). Classes at tip: CC0-vetted (Kenney/Quaternius/OGA — licence archived + hash at fetch, zero spend) and org-authored. Pending: the generated-art class — no AI-generated asset promotes to production until that founder-ruled class lands (the Vietnam photoreal plate stays demo for exactly this reason). Avatar exception (2026-08-06): static rights-clean sprite components allowed; state/behavior stays procedural.

§8 — Failure doctrine

  • Fail visibly: need() throws by name at load; UnknownFloor raises; unknown prop/activity kinds are validation errors — never silent defaults.
  • Fail closed: unrouted writes 404; disarmed actions refuse; empty evidence is NO-EVIDENCE, not success.
  • Selftest (158) gates every merge, but green ≠ floor works — T4 browser smoke and the §3.3 integration audit class exist because collector tests cannot see a dead page.
